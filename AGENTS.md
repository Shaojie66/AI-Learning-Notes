# Public learning notes

- Root README.md is the reading index. Standalone articles use SCEM-公开版-主题.md.
- Publish only reviewed general explanations, original teaching examples and learning experience.
- Exclude official course attachments, assessed answers, personal classroom data, credentials and private-vault paths.
- Preserve existing articles; review edits and verify runnable R examples before publication.
- Ask the owner before public updates. Do not add an open license without authorization.
- FOAI exception (lecturer permission by email, 2026-10-09): `FOAI/` may contain translations, slide-by-slide annotations and bilingual notebook versions of course material. Every FOAI note must credit the course lecturers generically, link the course repository, and state it is an unofficial personal note. Never include exercise solutions or non-public material (lecture recordings, transcripts). Material by other lecturers needs their own permission first. Per owner's request (2026-10-27), public notes omit the institution name, course code and individual lecturer names.
